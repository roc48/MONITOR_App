# MONITOR_App

this is the Code for MONITOR article

## Driectory structure

 - **`android/`**: Source code for the Android mobile application used to control and monitor the system.

 - **`embedded/`**: The firmware code of ESP32 microcontroller used in the  hardware.

 - **`PCB/`**: Includes the circuit schematic, PCB layout, and BOM for the PCB board used in this article.

## Compile Guide

Clone the repository using `git clone https://github.com/Crown1983/MONITOR_App.git`

 - The source code in the **`android/`** folder can be compiled with Android Studio to generate an APK file for Android smart devices.

 - The ESP32 firmware code in the **`embedded/`** folder can be built using ESP-IDF and flashed into ESP32-WROOM series chips.
